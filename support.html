使用问题

如果你在使用 CountPush 时遇到问题（计数不准、摄像头无法打开、订阅恢复等），请到 GitHub Issues 提交反馈，我们会尽快回复。

前往 GitHub Issues 提交问题 →

也可以发送邮件至 XIANGuoxin520@icloud.com。

订阅与恢复购买

  • 订阅通过 Apple 的 App Store 管理，可在 系统设置 → Apple ID → 订阅 中查看或取消。
  • 换设备后，在「我的」页面点击「恢复购买」即可恢复会员。
